# Statie-Meteo
Proiectul ales este o stație meteo, în cadrul căreia am creat trei tipuri de echipamente cu parametri diferiți: balon, radar și pluviometru.
Am folosit un dicționar pentru a imita proprietățile unei clase.
Cea mai complicată parte a fost imitarea unei proprietăți private.
Am luat în considerare o soluție bazată pe apeluri de funcții și ruperea referinței, dar am ales să nu complic implementarea inutil.
